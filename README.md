# WINDOWS-PERSISTENCE-INVESTIGATION 

Windows Persistence Investigation

1. Project Overview

This project simulates a Security Operations Center (SOC) investigation into potential persistence mechanisms on a Windows workstation.

The objective is to identify programs and configurations that may allow software to automatically execute when Windows starts or when a user logs in.


2. Investigation Scenario

A Windows workstation has been reported to behave unusually after system restarts.

As a SOC analyst, I was tasked with investigating the system for possible persistence mechanisms and identifying any suspicious startup activity.

3. Investigation Objectives

* Identify programs configured to start automatically.
* Investigate Windows startup locations.
* Examine Registry Run Keys.
* Investigate scheduled tasks.
* Identify potentially suspicious entries.
* Collect and document evidence.
* Determine whether malicious persistence is present.
* Map relevant findings to MITRE ATT&CK techniques.


4. Tools Used

* Windows 10/11
* PowerShell
* Windows Registry
* Task Scheduler
* Windows Event Viewer
* Windows built-in security tools
* GitHub

5. Investigation Methodology

The investigation will be performed in stages:

1. Examine Windows startup programs.
2. Investigate Registry Run Keys.
3. Examine scheduled tasks.
4. Investigate suspicious processes and files.
5. Analyze collected evidence.
6. Identify Indicators of Compromise (IOCs).
7. Map findings to MITRE ATT&CK.
8. Document the investigation and recommendations.
